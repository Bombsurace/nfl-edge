Favorite vs. underdog picks

The EV rule selects an underdog 69% of the time — and loses badly on them, while the favorite picks it does make are close to a fair, efficient market.

positive ROI negative ROI
Why: sportsbooks shade underdog prices to account for the public overbetting longshots (favorite–longshot bias). When a simple Elo model disagrees with the market most on a big underdog, that gap is far more often the model being wrong than the market being wrong — but the “take the higher-EV side” rule can’t tell the difference.

By claimed edge

If the edge number meant what it claims, ROI should climb as claimed edge rises. Instead it’s roughly the opposite — the biggest “edges” are the least reliable ones.

Takeaway: tightening the required edge for underdogs (tested at up to +15%) only shrinks the sample — it doesn’t fix the ROI. This is a calibration problem, not a threshold problem.

What to test next

In priority order — each should go through the same walk-forward backtest before being trusted, never adopted off one good week.

  1. Shrink toward the market. Blend model probability with the market's no-vig implied probability before computing EV (e.g. 30% model / 70% market) — directly targets the underdog overconfidence found above.
  2. Cap or exclude long underdogs from consideration rather than trying to fix them with a higher edge bar, which this run showed doesn't work.
  3. Situational features (rest, short week, travel, divisional games) — only if a feature demonstrably improves the backtest, since the market already prices most of this in.
  4. Training-window sensitivity — compare 2022–2025 vs. 2023–2025 vs. season-weighted, holding everything else fixed.
  5. Closing-line value — once a season of live snapshots accumulates, check whether the line moves toward the model's picks after they're made.
